# Projeto – Catálogo de Música

## Sobre o projeto
O objetivo deste projeto é desenvolver um catálogo de música, com páginas para login, menu, cadastro de artistas, cadastro de músicas e listagem.

Nesta primeira etapa, será desenvolvida apenas a parte de front-end, utilizando HTML5 e CSS3, criando a estrutura e o visual das telas.

## Objetivo
A ideia é construir um sistema completo de catálogo musical, permitindo organizar artistas e suas respectivas músicas.

As outras partes do projeto, como back-end, banco de dados, sistema de login funcional e cadastro de informações, serão desenvolvidas nas próximas aulas.

## Tecnologias utilizadas
- HTML5
- CSS3
- GitHub

## Desenvolvimento
O projeto será realizado em etapas, acompanhando o conteúdo das aulas e aplicando os conhecimentos adquiridos em equipe.
